# 03-drafts

Versioned prose, created by prose-editing roles when they run:

- `draft-v0-raw.md` — author's raw prose, if any
- `draft-v1-after-070-черновик.md`
- `draft-v2-after-080-структурщик.md`
- `draft-v3-after-090-стилист.md`
- `draft-v4-final-candidate.md`
- `draft-v5-after-150-финред.md`

Revision loops continue the numbering (`draft-v6-after-080-структурщик.md`, …). Stable paragraph IDs: `docs/stable-paragraph-ids.md`.
